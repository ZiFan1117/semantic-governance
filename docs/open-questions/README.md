## 关于最后两条

08 和 09 是**框架对自己**的质疑，不是普通工程问题：

- **08**：如果治理真正难的是组织而非机制，那框架第一部分（治理）就从"核心设计"降级为"机制清单"
- **09**：如果"强 TBox"只适用于少数场景，那框架的定位应该改成"面向多消费者场景"，而不是暗示"所有组织都需要"

**它们单列，是为了不被淹没在工程问题里。**
