## 1. 接口

| 操作 | 输入 | 输出 |
|---|---|---|
| `Query` | 模式（subject / relation / object 的任意组合） | 事实列表 |
| `Traverse` | 起点 + 关系路径 + 深度 | 可达实例与路径 |
| `Infer` | 派生目标 | **含派生的**事实列表（每条带 `via`） |
| `Search` | 文本 | 命中的事实 |

## 2. 通用约定

### 2.1 结果信封

**所有操作的返回 MUST 使用统一信封：**

```json
{
  "items": [ ... ],
  "truncated": false,
  "snapshot": 5,
  "budget": { "max_items": 100, "returned": 12 },
  "bypass_permission_filter": false
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `items` | ✅ | 结果项 |
| `truncated` | ✅ | **是否因预算被截断** |
| `snapshot` | ✅ | 本次查询所依据的快照（`R-5` 同理：可重现） |
| `budget` | ❌ | 预算与实际返回量 |

### 2.2 三条硬条款

| # | 条款 | 理由 |
|---|---|---|
| **Q-1** | **截断 MUST 显式**（`truncated: true`），**MUST NOT** 静默返回部分结果 | Agent 会把不完整当完整，据此做错决策 |
| **Q-2** | 同一次查询的**所有读取 MUST 基于同一快照** | 否则结果自相矛盾 |
| **Q-3** | 结果顺序 **MUST** 确定 | 否则无法缓存、无法复现 |

## 3. 派生事实

### 3.1 语义

Ossie 的 `derived_by` 定义"由其他事实推出的事实"。
这些事实**不落库**（框架 `I2-4`），**在查询时求值**。

### 3.2 溯源（**本规范的核心**）

> **每条派生事实 MUST 携带 `via`，说明它是被哪条规则、从哪几条事实推出的。**

```json
{
  "subject": "urn:...:Person:alice",
  "relation": "ancestor_of",
  "object": "urn:...:Person:carol",
  "derived": true,
  "via": {
    "rule": "Person.ancestor_of",
    "case": 1,
    "expression": "Person.ancestor_of.parent_of(descendant)",
    "premises": [
      { "subject": "urn:...:Person:alice",
        "relation": "ancestor_of", "object": "urn:...:Person:bob" },
      { "subject": "urn:...:Person:bob",
        "relation": "parent_of", "object": "urn:...:Person:carol" }
    ]
  }
}
```

| 字段 | 说明 |
|---|---|
| `derived` | 恒为 `true`（用于区分存储的事实与推出的事实） |
| `via.rule` | 哪条派生定义（<概念>.<关系>） |
| `via.case` | 该定义的第几条 `derived_by` 表达式（**从 0 计**） |
| `via.expression` | 该表达式原文 —— **让调用方不必回查定义** |
| `via.premises` | 所依据的事实（最小支持 1~2 条） |

> **没有 `via` 的派生事实是"无理由的断言"。**
> Agent 拿着它无法回答"凭什么"，也就无法验证 —— 这正是框架 §20.8 `A-2` 的要求。

### 3.3 最小表达力（**明确边界**）

**支持的派生表达式形式：路径型**

```
<概念>.<关系1>[.<关系2>...](<角色名>)
```

| 情形 | 形式 | 例 |
|---|---|---|
| **基础** | `C.r(role)` | `Person.parent_of(descendant)` |
| **递归** | `C.<自身>.r(role)` | `Person.ancestor_of.parent_of(descendant)` |
| **泛化路径** | `C.r1.r2(role)` | `Order.shipment.carrier(role)` |

**不支持（MUST 明确拒绝，不得静默忽略）：**

| 不支持的形式 | 例子 |
|---|---|
| 布尔组合 | `A.files_single AND A.earns <= 11925` |
| 比较与算术 | `Amount > 0.0` |
| 否定 | `NOT EXISTS(...)` |
| 聚合 | `COUNT(...)` |

> **遇到不支持的表达式，实现 MUST 报错或标注"未支持"，MUST NOT 当作空结果。**

### 3.4 求值算法：不动点

```
重复：
    对每条派生定义、每条 derived_by 表达式：
        扫描当前事实集，尝试匹配
        若产生新事实 → 加入工作集，记录 via
直到一轮下来没有新事实
```

**这是框架 §14 描述的"前向链到不动点"的最小实现。**

**条款：**

| # | 条款 |
|---|---|
| **D-1** | 派生 **MUST** 求值到不动点 |
| **D-2** | 派生事实 **MUST NOT** 被持久化（框架 `I2-4`） |
| **D-3** | 实现 **MUST** 声明支持的表达式形式；不支持的 **MUST** 报错 |
| **D-4** | 实现 **MUST** 有迭代上限，超限 **MUST** 报错而非静默停止 |
| **D-5** | 同一事实有多条推导路径时，**MAY** 只返回其中一条，但 `via` **MUST** 真实反映该路径 |

**关于 D-4**：递归派生可能不终止（框架 §14 已指出）。
**必须给上限**，且超限要**报错**，不能悄悄停下来交出一个不完整的闭包 ——
那正好违反 `Q-1` 的立意。

## 4. 遍历

```
Traverse(from, path, max_depth, budget) → { items: [ { instance, path, hops } ] }
```

| 条款 | 说明 |
|---|---|
| **T-1** | **MUST** 支持多跳；深度由调用方指定 |
| **T-2** | **MUST** 检测环并终止（不得无限展开） |
| **T-3** | **MUST** 返回到达路径（便于解释"怎么连上的"） |
| **T-4** | 到达同一实例的多条路径 **MAY** 只返回最短的一条 |

---

## 5. 检索

```
Search(text, budget) → { items: [ { subject, relation, object, matched_field } ] }
```

**最小版只做字面匹配**（对字面量对象的子串匹配）。

| # | 条款 |
|---|---|
| **S-1** | 最小实现 **MUST** 至少支持字面量匹配 |
| **S-2** | 结果 **MUST** 标明命中字段 |
| **S-3** | 语义检索（向量）**SHOULD** 由实现另行提供，**MUST** 与字面匹配可区分 |

## 6. 规范性条款汇总

| 组 | 条款 |
|---|---|
| **通用** | Q-1 截断 MUST 显式 · Q-2 同一快照 · Q-3 顺序确定 |
| **派生** | D-1 求值到不动点 · D-2 不落库 · D-3 声明支持的表达式 · **D-4 迭代上限且超限报错** · D-5 多路径 MAY 择一 |
| **遍历** | T-1 多跳 · T-2 检测环 · T-3 返回路径 · T-4 MAY 只返最短 |
| **检索** | S-1 字面匹配 · S-2 标明命中字段 · S-3 语义检索需可区分 |
| **保证**（框架 §12） | G1 只读 · **G2 可追溯（`via`）** · G3 权限过滤 · G4 预算可限 |

## 7. 一致性验收

| # | 验收项 |
|---|---|
| 1 | 基础派生：给定 `a→b, b→c`，`Infer` **必须**返回 `a→c`，且 `via.case` 指向递归规则 |
| 2 | **溯源真实性**：`via.premises` 里的每条前提 **必须**在存储中真实存在（或本身是派生事实） |
| 3 | **不动点**：`a→b→c→d` **必须**推出 `a→d`（需 2 轮迭代） |
| 4 | **不落库**：`Infer` 之后，`Query` **不得**返回派生事实 |
| 5 | **截断显式**：设 `max_items=1` 而实际有 3 条，**必须** `truncated: true` |
| 6 | **不支持的表达式**：含 `AND` 的 `derived_by` **必须**报错或标注未支持 |
| 7 | **环终止**：`a→b→a` 的传递闭包 **必须**终止 |
| 8 | 权限过滤：不可见的事实 **不得**出现在结果中 |
| 9 | 快照一致：同一次 `Infer` 的所有读取基于同一快照 |
